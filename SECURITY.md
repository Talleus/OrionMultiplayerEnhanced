# Security

This preview is intended for trusted LAN/private-VPN peers, not untrusted public servers.

Use GitHub **Security → Report a vulnerability** when available. Do not publish credentials, personal saves, private addresses, or working exploits against others' servers.

Setup verifies the embedded game archive, each extracted file, and the complete modified SWF before completing installation in a new folder. It does not require or read another game installation. Uninstall validates ownership and preserves added/modified files. The executable is unsigned; verify release SHA-256 checksums. A checksum is not a code signature.
